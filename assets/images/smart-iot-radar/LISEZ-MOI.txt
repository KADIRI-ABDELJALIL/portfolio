DOSSIER DES IMAGES DU PROJET : smart-iot-radar

1. Deposez ici vos images (PNG, JPG ou WebP, idealement moins de 500 Ko).
2. Nommez-les avec : minuscules, sans espaces, sans accents. Exemple : 01-vue-ensemble.png
3. Declarez-les dans content/projects.js, dans le bloc du projet "smart-iot-radar" :
   images: [
     { src: "assets/images/smart-iot-radar/01-vue-ensemble.png",
       alt: { fr: "Vue d'ensemble", en: "Overview" } }
   ],
Masquez avant publication les plaques, adresses IP, cles et identifiants visibles sur une capture.

NOTE : les 3 images actuelles du radar sont encore directement dans assets/ (leurs noms sont
references dans content/projects.js). Vous pouvez les deplacer ici plus tard, a condition de mettre
a jour les chemins dans content/projects.js.
