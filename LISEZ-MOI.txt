PORTFOLIO - GUIDE RAPIDE
Adresse du site : https://kadiri-abdeljalil.github.io/portfolio/

ORGANISATION DES FICHIERS
  index.html, projects.html     Structure des pages (a ne pas modifier)
  style.css                     Couleurs et design (variables en haut du fichier)
  script.js                     Animations et affichage automatique
  content/site.js               Vos infos : e-mail, liens (CV, LinkedIn, GitHub), competences, textes FR/EN
  content/projects.js           TOUS les projets
  content/modele-projet.txt     Modele a copier pour ajouter un projet
  assets/cv.pdf                 Votre CV (renvoyez un fichier de meme nom pour le mettre a jour)
  assets/og-image.png           Miniature LinkedIn
  assets/images/<id-projet>/    Images de chaque projet (un dossier par projet)
  assets/docs/                  Autres documents

AJOUTER UNE IMAGE A UN PROJET
  1. Nommez-la en minuscules, sans espaces ni accents : 01-vue-ensemble.png
  2. Deposez-la dans assets/images/<id-du-projet>/
  3. Dans content/projects.js, dans le bloc du projet, ajoutez-la a la ligne images (voir LISEZ-MOI.txt du dossier).

AJOUTER UN PROJET
  1. Ouvrez content/modele-projet.txt et copiez le bloc.
  2. Collez-le dans content/projects.js, entre deux projets, puis remplacez les textes.
  3. Creez le dossier assets/images/<id-du-projet>/ si vous avez des images.

MODIFIER UN TEXTE, UN LIEN OU UNE COULEUR
  Liens, e-mail, competences, textes : content/site.js
  Couleurs : variables en haut de style.css
  Chaque modification : sur GitHub, ouvrez le fichier, cliquez sur le crayon, puis "Commit changes".
  Pour envoyer plusieurs fichiers : Add file > Upload files.
  Apres 1 a 2 minutes, verifiez dans une fenetre privee (Ctrl + Maj + N).

REGLES UTILES
  - Dans les fichiers .js, gardez les guillemets, les virgules et les accolades.
  - Aucun nom de personne ni lien externe sans decision de votre part.
  - Ne publiez jamais de cle, mot de passe ou donnee confidentielle (le depot est public).
