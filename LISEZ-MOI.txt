AK ENGINEERING PORTFOLIO — V1
=============================
Ce dossier est une adaptation du dépôt original fourni, avec les mêmes pages HTML, le logo <AK/>, la palette, les particules, les animations et le moteur de fiches projets.

UTILISATION
- Extraire le ZIP ; ouvrir index.html dans un navigateur moderne, ou utiliser un serveur local (python -m http.server 8000).
- Pour GitHub Pages : remplacer les fichiers correspondants à la racine du dépôt (conserver les dossiers assets et content), puis vérifier le site publié. Le site public n'a pas été modifié par ChatGPT.
- Modifier content/site.js pour le profil et les compétences ; content/projects.js pour les fiches ; content/extra.js pour les parcours, certificats, contact et autres sections.

POINTS À FINALISER / VÉRIFIER AVANT PUBLICATION
- Le sélecteur FR/EN/AR et la direction RTL sont opérationnels ; certains anciens paragraphes détaillés et légendes restent en français en mode arabe.
- Adresse e-mail alignée sur le CV fourni (.ma au lieu de .com dans l'ancien site) : confirmer qu'elle reçoit les messages.
- Les logos FSO/OCP non récupérables dans cet environnement sont remplacés par des sigles neutres ; les logos des outils ne sont pas tous disponibles. Ajouter les fichiers officiels lorsque disponibles.
- Certificat SNEE : image publique avec numéro étudiant masqué. Les PDF originaux des attestations ne sont pas distribués dans le dépôt. Le CV reste téléchargeable et comporte les coordonnées indiquées dans le CV fourni.
- La vidéo de présentation CCPS est hébergée sur le site source ; la lecture externe n'a pas été vérifiée. Les vidéos locales sont des benchmarks intermédiaires, pas une démonstration finale.
- Les images QualiVision sont explicitement conceptuelles ; les remplacer par les résultats réels. Le certificat Simulink n'a pas été fourni ; aucune vignette n'a été inventée.
- Certaines anciennes illustrations de projet ne sont pas reprises dans les galeries publiques, afin d'éviter les mentions d'encadrement et les chiffres fictifs non identifiés. Un flyer CCPS distinct n'était pas disponible dans le lot de médias.
